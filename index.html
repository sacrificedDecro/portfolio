What I've built

Dead rails - drag, weight & throw
Players can pick up, carry, and throw physics objects, with weight changing how each one feels. The server checks that the player is close enough and allowed to interact before moving an item. Weight, throw force, and interaction range can be adjusted for each object.
Gist
Simple combat system
Close-range combat with M1 and M2 combos, blocking, sprint attacks, back attacks, knockback, hit sounds, and blood effects. Damage, targets, and cooldowns are handled on the server instead of being chosen by the client. Training dummies make it easy to test attacks and blocks while building the game.
Gist
R6 & R15 ragdoll system
Ragdoll for both R6 and R15 characters. Players can toggle it on and off, the camera follows while the character is down, and death ragdolls stay in the world. The server controls the state and limits rapid requests so the system stays predictable in multiplayer.
Gist View on Roblox
Inventory slot UI & custom interact prompt
Players can pick up tagged world items, place them in three slots, equip them, and drop them back into the world. Before an item moves, the server checks the item, distance, free slot, and ownership, helping prevent duplicate pickups. The slot UI and custom prompts can be adapted to your own item definitions.
Gist
Tink — game framework
Strictly typed Knit-style framework for Roblox services and controllers, built around Spark modules rather than the archived Knit codebase. It provides remote signals, remote properties, unreliable signals, per player rate limiting, module discovery, and staged startup with timeouts. Evaera Promise handles asynchronous startup hooks.

Payment

How I work

Most commissions are paid per task. We agree on clear steps, and you pay after each one is delivered. A 50/50 split also works: half before I start and half on delivery. I accept Robux, Mastercard transfers, gift cards, and crypto. I do not take revenue share or payment after a game ships.

Ownership

As soon as a task is paid for, that code is yours. You can modify it, ship it anywhere, and I don't keep a copy.

Refunds

You can stop at any time. With per-task work, you only pay for what has been delivered. With 50/50, the upfront half is refundable until I start.

Availability

I'm available 6-12 hours a day (UTC+3). I reply within hours on Discord.
