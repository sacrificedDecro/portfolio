Cooking System

Server-side crafting chain built in --!strict Luau. Players collect world props — MixingPot, TabBinder, EnergyExtract — via ProximityPrompt interactions, place the pot on a table slot, then add both ingredients sequentially. Per-player CraftState tracks every step. Tween-based fade animations handle prop spawning and removal. Tool inventory persists across character death via a pendingTools queue restored on CharacterAdded. All constants centralised in a typed GameConfig module.

EXPLORE THE STRUCTURE

Dead Rails Drag System + Throw and Weight ( multiplayer )

A multiplayer first-person drag, weight, and throw system written in full --!strict Luau with a centralised GameConfig ModuleScript as the single source of truth for all constants and shared utilities. Parts carry a Weight attribute initialised per-object by the server; heavier parts reduce AlignPosition responsiveness and max velocity proportionally, creating authentic physical resistance during drag. The SelectionBox outline interpolates between configurable light and heavy colours, giving instant visual weight feedback before the player even grabs an object. On release, the client computes throw velocity from a sliding time-window sample of DragAttachment.WorldPosition deltas, sends it to the server, which scales and caps it by weight before applying AssemblyLinearVelocity.
